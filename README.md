# FlashCard App

My first project in TripleTen's AI-Assisted Software Engineering program. It includes decks of flashcards, each of which can be viewed in a carousel. This app is designed to help beggining software engineers get acquanited with HTML, CSS, JS and Git fundamentals.

## Deployed Site

Check out [this site](https://donovan1palmer-cyber.github.io/ai-se_project_flashcards/) on GitHub Pages.

## Features

- Browse flashcard decks in the gallery
- Open a deck to view and manage its flashcards
- Practice a deck in a carousel, flip cards to reveal answers, and navigate between cards
- Responsive layout for desktop and mobile screens
- Delete decks and flashcards

## Technologies Used

- HTML
- CSS
- JS
- GIT
