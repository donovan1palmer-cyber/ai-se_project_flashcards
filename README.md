# FlashCard App

My first project in TripleTen's AI-Assisted Software Engineering program. It includes decks of flashcards, each of which can be viewed in a carousel. This app is designed to help beggining software engineers get acquanited with HTML, CSS, JS and Git fundamentals.

## Features

- Add new flashcards
- Flip cards to reveal the answer
- Delete cards you no longer need

## Technologies Used

- HTML
- CSS
- JS
- GIT
